# Population tiles for NuclearWarHeads

Pre-processed 1° population tiles (30″ cells, gzip'd little-endian uint32) used by the
[NuclearWarHeads](https://github.com/shubhamteke45/NuclearWarHeads) casualty estimates.
Built with `scripts/population/build_tiles.py` in that repository.

**Source:** GHSL — Global Human Settlement Layer, GHS-POP R2023A (epoch 2025, 30 arc-second).
Schiavina M., Freire S., Carioli A., MacManus K. (2023): GHS-POP R2023A - GHS population grid
multitemporal (1975-2030). European Commission, Joint Research Centre (JRC).
doi:10.2905/2FF68A52-5B5B-4A22-8F40-C41DA8332CFE. Licensed CC BY 4.0.
